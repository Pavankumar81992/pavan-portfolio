# Personal Portfolio Website

A responsive personal portfolio website developed to showcase my professional profile, technical skills, projects, education, and contact information.

## About the Project

This portfolio represents my journey as an aspiring Full Stack Developer. It provides an overview of my technical background, practical projects, and professional interests through a clean and user-friendly interface.

## Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* JavaScript
* Bootstrap Icons

## Features

* Responsive design for desktop, tablet, and mobile devices.
* Professional introduction and about section.
* Technical skills and project showcase.
* Educational background.
* Resume download functionality.
* Functional contact form integrated with Formspree.
* LinkedIn and GitHub profile links.
* Interactive navigation and smooth scrolling.

## How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Pavankumar81992/pavan-portfolio.git
   ```

2. Open the project folder in VS Code.

3. Open `index.html` using Live Server or your preferred browser.
